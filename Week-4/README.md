# Week 4 – Predictive Modeling for Agribusiness Insights

## Objective

The objective of Week 4 is to develop a predictive model for estimating crop yield using agribusiness data.

## Dataset

The dataset contains information related to crops, cultivated area, production, and yield.

### Features

- State
- District
- Crop
- Season
- Area
- Production
- Yield

## Methodology

1. Load the agribusiness dataset.
2. Inspect and clean the data.
3. Select relevant features for prediction.
4. Split the data into training and testing sets.
5. Train a machine learning regression model.
6. Evaluate the model using regression metrics.
7. Visualize the actual and predicted yield values.

## Machine Learning Model

A **Random Forest Regressor** is used to predict crop yield.

## Evaluation Metrics

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Expected Outcome

The model predicts crop yield based on available agribusiness features and demonstrates how machine learning can support data-driven agricultural insights.
