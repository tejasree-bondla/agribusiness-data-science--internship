# Week 3 – Exploratory Data Analysis and Visualization

This folder contains the Week 3 EDA work for the Agribusiness Data Science internship.

## Objective
The analysis explores crop production patterns using descriptive statistics and visualizations. The main focus is crop performance, cultivated area, production, yield, and seasonal differences.

## Dataset
The cleaned dataset from Week 2 is used as the starting point. The dataset contains:
- District
- Crop
- Season
- Area_Ha
- Production_Tonnes
- Yield_Tonnes_Per_Ha

## Analysis Performed
1. Dataset inspection
2. Descriptive statistics
3. Crop-wise production analysis
4. Crop-wise yield analysis
5. Area vs production relationship
6. Season-wise production analysis
7. Agribusiness interpretation

## Tools
- Python
- Pandas
- Matplotlib

## Files
- `data/agribusiness_cleaned.csv` – cleaned dataset used for EDA
- `scripts/eda_analysis.py` – Python EDA and visualization script
- `visualizations/` – generated charts
- `Week_3_Agribusiness_EDA_Report.docx` – final report

## Note
The working dataset is small, so the results are exploratory and should not be treated as general conclusions. Larger multi-year datasets with rainfall, irrigation, inputs, prices, and market variables would support deeper analysis.
